# CryptoGuardian — Project Overview

> AI-powered portfolio protection agent for the MetaMask Smart Accounts Kit x 1Shot API x Venice AI Hackathon

---

## What It Does

CryptoGuardian monitors ALL major volatile EVM coins simultaneously. Every 15 minutes, Venice AI acts as a crypto guru — analyzing price momentum, news, and sentiment across all watched coins. When it detects danger in any coin, it auto-swaps that coin to USDC. When it spots opportunity, it can buy more — all within strict user-defined limits enforced onchain via MetaMask Smart Account permissions.
