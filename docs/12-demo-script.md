# Demo Script — 3 Minute Hackathon Video

## Narrative Arc

Problem → Solution → Live Demo → Impact

---

## Script

### 0:00 — 0:20 | Hook (Problem)

**Screen:** Dark screen, then news headline montage — crypto prices crashing

**Voiceover:**

> "ARB down 15%. PEPE flash crash 30%. SHIB rug pull news. Most people find out after the damage is done — hours later, when it's too late."

**Cut to:** Portfolio graph going red

> "What if your portfolio had a guardian watching 24/7?"

---

### 0:20 — 0:50 | Solution Reveal

**Screen:** CryptoGuardian landing page loads

**Voiceover:**

> "CryptoGuardian is an AI-powered protection agent that monitors 10 volatile EVM coins simultaneously, every 15 minutes, while you sleep."

**Screen:** Tech stack logos animate in

> "Venice AI acts as your crypto guru. MetaMask Smart Accounts handle permissions so it never needs your signature again. 1Shot API pays all gas in USDC — no ETH needed."

---

### 0:50 — 1:20 | Setup Demo

**Screen:** Setup page walkthrough

**Voiceover:**

> "Setup takes 2 minutes. Connect MetaMask, select the coins you hold, set your limits per coin — max swap, daily cap, minimum to always keep."

**Screen:** Permission grant UI

> "Grant permissions once. CryptoGuardian protects you for 30 days. No repeated signing. No popups at 3am."

---

### 1:20 — 2:20 | Live Dashboard Demo

**Screen:** Dashboard — VerdictGrid showing all 10 coins

**Voiceover:**

> "The verdict grid shows your entire portfolio at a glance. Green is opportunity. Yellow is caution. Red is danger."

**Screen:** One coin flips to 🔴 DANGER — ARB

> "Right now, ARB just dropped 15% after negative governance news. Venice AI flagged it DANGER — let's see why."

**Screen:** PriorityCoin panel expands with Venice reasoning

> "'ARB has dropped 15% in 1 hour following negative governance news and elevated Fear index at 22. Momentum indicators suggest continued downside — moving to USDC protects capital before further deterioration.'"

**Screen:** Agent feed shows new entry: "ARB → USDC swap executing..."

> "The agent automatically swaps within the user's $300 limit — gas paid in USDC via 1Shot, no ETH needed."

**Screen:** Transaction confirmed on Basescan

> "15 seconds later — confirmed on Base. $300 protected."

---

### 2:20 — 2:45 | Opportunity Side

**Screen:** LINK flips to 🟢 OPPORTUNITY

**Voiceover:**

> "Meanwhile, LINK just surged on a major oracle partnership announcement. Venice spots the opportunity — and if the user has aggressive settings enabled, it buys more — automatically."

**Screen:** Settings showing "Aggressive" mode + opportunity buy

---

### 2:45 — 3:00 | Closing

**Screen:** Portfolio score — "$1,247 protected this week"

**Voiceover:**

> "Your portfolio. Protected by AI. Powered by Venice, MetaMask, and 1Shot."

**Screen:** Logo + links

> "CryptoGuardian — built for the MetaMask Smart Accounts Kit x 1Shot x Venice AI hackathon."

---

## Demo Setup Checklist

Before recording:

- [ ] App deployed to Vercel
- [ ] Test wallet funded with small amounts on Base
- [ ] Smart Account upgraded and permissions granted
- [ ] All 10 coins showing in verdict grid
- [ ] Pre-stage a DANGER scenario (or use live data if timing is right)
- [ ] Dashboard showing recent action in feed
- [ ] Screen recording at 1920x1080
- [ ] Good microphone / voiceover recorded separately
